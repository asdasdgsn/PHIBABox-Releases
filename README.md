# PHIBABox 版本发布

这是 PHIBABox 的公开更新渠道，仅存放安装包、更新说明与更新索引，不包含应用源码。

## 用户更新

首次安装带有更新功能的 PHIBABox 后，可在应用菜单选择「检查更新…」，或在「设置 → 版本更新」操作。自动检查可以自行开启。

当前渠道初始化完成，尚未发布可下载的正式安装包。后续正式版本将在 [Releases](https://github.com/asdasdgsn/PHIBABox-Releases/releases) 提供。当前发行目标为 Apple Silicon、macOS 14 及以上。

## 更新安全

正式版本使用 Developer ID 签名、公证及 Sparkle Ed25519 更新包签名。请勿从不明来源替换 App 或更新源。资料库与 Eagle 原文件不会包含在更新包内。

`appcast.xml` 是客户端使用的更新索引。
